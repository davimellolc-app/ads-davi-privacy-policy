Política de Privacidade — ads-davi

Última atualização: 11 de agosto de 2026

Esta política descreve como o aplicativo ads-davi trata dados ao se conectar à API da Meta (Facebook/Instagram Marketing API e Ad Library API). O ads-davi é uma ferramenta de uso pessoal/interno, criada e operada por seu desenvolvedor para gerenciar e analisar suas próprias contas de anúncios. Ele não é distribuído a terceiros nem coleta dados de usuários finais.

1. Quem opera este aplicativo

O ads-davi é mantido por uma pessoa física, para uso próprio, com o objetivo de automatizar relatórios, regras de otimização de campanhas e análise de criativos publicitários das contas de anúncio de propriedade do próprio operador.

2. Dados acessados

Ao se conectar às APIs da Meta, o aplicativo pode acessar:

  • Dados de desempenho de campanhas, conjuntos de anúncios e anúncios (métricas, gastos, status) das contas de anúncio autorizadas pelo próprio operador;
  • Dados públicos de anúncios disponibilizados pela Meta Ad Library API (texto de criativos, período de veiculação e mídia associada a anúncios publicamente visíveis);
  • Identificadores técnicos necessários para autenticação (token de acesso do tipo System User).

O aplicativo não coleta, processa ou armazena dados pessoais de usuários finais (ex.: visitantes de anúncios, clientes de terceiros). Nenhum dado é coletado de pessoas que não sejam o próprio operador da ferramenta.

3. Como os dados são usados

  • Geração de relatórios de performance das próprias contas de anúncio;
  • Execução de regras automatizadas de otimização de campanha (ex.: pausar anúncios com baixo desempenho);
  • Análise de criativos (transcrição de áudio, detecção de cortes de cena e silêncio) de anúncios públicos da Ad Library, para fins de benchmarking e inspiração criativa.

4. Armazenamento e retenção

Os dados processados ficam armazenados localmente, em ambiente controlado pelo operador (arquivos de relatório e mídia baixada para análise). Nenhum dado é compartilhado, vendido ou transferido a terceiros. Nenhum banco de dados remoto ou serviço de terceiros é usado para armazenar esses dados.

5. Compartilhamento de dados

O ads-davi não compartilha, vende ou transfere dados a terceiros. As únicas comunicações de rede realizadas pelo aplicativo são diretamente com as APIs oficiais da Meta, usando credenciais de propriedade do próprio operador.

6. Segurança

Tokens de acesso e credenciais são armazenados apenas localmente, em ambiente controlado pelo operador, e não são publicados ou expostos publicamente.

7. Alterações nesta política

Esta política pode ser atualizada periodicamente para refletir mudanças no funcionamento do aplicativo. A data da última atualização está indicada no topo desta página.
